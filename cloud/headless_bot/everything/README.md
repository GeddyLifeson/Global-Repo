# Test everything in the game (S6986, S6987)
1. `python3 -I manifest.py <pack mods dir or jars> -o manifest.json` (S6986): static census plus recipe checks (unknown result or ingredient, identical-input conflicts or duplicates, items with no obtain path).
2. `python3 -I run_all.py manifest.json --rcon HOST:PORT:PASS --out report` against a running server (C:\MCTestServer with enable-rcon=true), or `--jars J...` to boot a cloud Lane (S6854). `--client` adds a joined survival player for boss fights and screenshots. (S6987)
Result: `report/report.tsv` (category, id, PASS/FAIL/UNTESTED, detail, evidence path), `REPORT.md`, `evidence/<category>/<id>.log` holding the server's own command feedback.
How each thing is tested: block = setblock + read back; item = put in a container + read back; entity = summon, 2.5 s later still ticking; recipe = fill a vanilla Crafter with the exact inputs, power it, compare the dropped stack with the recipe's result id and count; dimension = load a chunk, place and read a block; command = registered via `help` (UNTESTED until an exec spec exists); boss (`--bosses id,id`) = spawn, alive, with `--client` fight a survival player, kill by player damage, loot vs loot table; machine (`--machines machines.json`) = spec-driven (block, slots, wait, expected output slot).
Non-crafting recipe types, KubeJS-script recipes and tag ingredients with no resolvable member are reported UNTESTED, never PASS. Tests run at spawn in the real overworld (cells at y=100), not backrooms.
